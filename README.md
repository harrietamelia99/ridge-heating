# Ridge Heating

One-page marketing site for Ridge Heating — independent gas engineer in Bristol & the Southwest.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
